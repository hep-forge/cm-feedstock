Feedstock for [cm](https://git.ligo.org/virgo/virgoapp/Cm) — part of [hep-forge](https://anaconda.org/hep-forge).
Builds linux-amd64 + linux-arm64 in one matrix workflow and uploads to the
[hep-forge](https://anaconda.org/hep-forge) Anaconda channel.

Virgo multitask communication package

## Architectures

State per architecture: see the platforms badge above or [anaconda.org/hep-forge/cm](https://anaconda.org/hep-forge/cm).


## Install

```bash
conda install -c hep-forge -c conda-forge cm
```
